# Project 2: Create & Manage S3 Bucket

## Objective
Create an S3 bucket, upload files, and manage permissions.

## AWS Services Used
- S3 (Simple Storage Service)
- IAM (for permissions)

## Steps
1. Go to S3 Console
2. Click "Create bucket"
3. Enter bucket name (globally unique!)
4. Choose region
5. Upload files (images, text, etc.)
6. Set permissions (Public/Private)
7. Enable versioning (optional)

## What I Learned
- S3 bucket names are globally unique across all AWS accounts
- Object storage vs Block storage
- Public vs Private access
- S3 versioning
